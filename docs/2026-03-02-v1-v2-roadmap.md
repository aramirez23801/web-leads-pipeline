## V1 — Complete the Node.js Pipeline

### Stage 8 — `8-emailcontent.mjs`
- Input: `content.json` + `leads_audited_{neighborhood}.xlsx`
- Calls Claude Haiku (`claude-haiku-4-5`) to generate:
  - `email_subject` — 5-8 words, personalized to business name + key issue
  - `email_body` — 150-200 words, plain text, Spanish. Includes `{{PREVIEW_URL}}` placeholder.
- Output: `{slug}_email.json` → `{ subject, body }`
- Resume-safe: skip if `{slug}_email.json` already exists
- `--dry-run`: print prompt + sample output, no API call

### Stage 9 — `9-deploy.mjs`
Cloudflare Pages Direct Upload API (free tier, commercial use allowed, unlimited deployments)

**URL format:** `https://{8hex}.{project}.pages.dev`

**API endpoints:**
```
CREATE: POST   /v4/accounts/{account_id}/pages/projects/{project}/deployments
LIST:   GET    /v4/accounts/{account_id}/pages/projects/{project}/deployments
DELETE: DELETE /v4/accounts/{account_id}/pages/projects/{project}/deployments/{deployment_id}
```

**Behavior:**
1. At run start: list all deployments, DELETE any with `created_on` > 15 days ago
2. For each lead: upload `mockdesign.html` (+ `logo.png` if exists) as multipart/form-data
3. Save returned URL as `previewUrl` in `{slug}_email.json`
4. Replace `{{PREVIEW_URL}}` placeholder in body with real URL
5. Resume-safe: skip if `previewUrl` already set in email.json
6. `--dry-run`: list what would be deployed/cleaned, no API calls

**Env vars:** `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN` (Pages:Edit permission), `CLOUDFLARE_PAGES_PROJECT`

**Note:** Direct uploads do NOT count toward the 500-build/month free limit.

### Stage 10 — `10-outreach.mjs`
- Reads all `{slug}_email.json` for the neighborhood
- Writes `outreach_{neighborhood}.csv`:
  - Columns: `name, email, subject, body, previewUrl, website, phone, category, score, tier`
- Resume-safe: append-only (skip slugs already exported)
- `--send` flag required to write file (default is dry-run that prints what would be exported)
- **No platform API in v1** — CSV is uploaded manually to Instantly.ai or Smartlead

## V2 — Production Improvements

### 2a. Email sending platform (start warmup now — longest lead time)
- Register separate sending domain (see `docs/2026-03-02-sending-domain-setup.md`)
- Configure SPF/DKIM/DMARC
- Connect to Instantly.ai or Smartlead (~$37/month)
- **4-6 week warmup required** before first real send
- After warmup: integrate platform API into stage 10. `--send` enrolls lead in sequence.

### 2b. Logo extraction upgrade
Improve `4-content.mjs` logo extraction hierarchy:
1. JSON-LD (`schema.org/Organization → logo`)
2. `<link rel="apple-touch-icon">` — high-res, always the real brand icon
3. `<meta property="og:image">`
4. `img[src*=logo]` (current)
5. Clearbit Logo API fallback (`clearbit.com/logo?domain=example.com`, free)

Add `node-vibrant` for real brand color extraction → replace `getCategoryColor()` guessing in stage 6.

### 2c. Stage 6 parallelization (easy win)
Change serial loop to `pLimit(3)`. Wall time: ~25 min → ~9 min for 30 leads.

### 2d. Scoring improvements
- Add `no tel: link on mobile` signal (+10) — direct revenue loss for restaurants, dentists
- Add `no <form>` signal (+10) — no contact form = losing leads
- Update review multiplier: `≥ 100 → 1.35`, `≥ 30 → 1.25`, `≥ 10 → 1.15`
- Consider PageSpeed API for Core Web Vitals (most credible signal for non-technical owners)

### 2e. Python migration (after v1 complete)
- Migrate one stage at a time, start with simplest (stage 5 or 10)
- Keep Node.js stages running until Python equivalent is tested
- Tools: `uv`/`poetry`, `playwright`, `anthropic`, `openpyxl`, `httpx`, `asyncio.Semaphore`

### 2f. GCP cloud deployment (when running 5+ neighborhoods/week)
```
Admin UI (Cloud Run Service, FastAPI)
  └── triggers → Cloud Run Job (pipeline runner per neighborhood)
                    └── reads/writes → GCS bucket (output/)
                    └── deploys → Cloudflare Pages API (mockup hosting)
```
- Cloud IAP for admin auth (zero auth code)
- GCS Object Lifecycle rules for 15-day mockup cleanup (eliminates stage 9 cleanup code)
- Playwright runs cleanly on Cloud Run `us-central1` base image
